# Stackly Preschool — Website Theme

A modern, colourful and fully responsive multi-page **Preschool / Kindergarten / Early Learning
Centre** website theme built with **only HTML5, CSS3 and Vanilla JavaScript** — no frameworks, no
build tools, no dependencies.

**Brand:** Stackly Preschool
**Tagline:** _Little Steps Today, Big Dreams Tomorrow!_

---

## 1. Features

- 12 hand-crafted pages with a consistent header, navigation and footer
- Sticky header + slide-out mobile navigation (hamburger, close button, ESC to close, focus trap)
- Announcement bar, active-page link highlighting
- Hero image carousel + auto-playing testimonials slider
- Animated statistic counters (IntersectionObserver)
- Scroll-reveal animations, back-to-top button, scroll-progress bar
- Gallery + activity + event category filtering
- Accessible image lightbox with next / previous / close and keyboard controls
- FAQ accordion, validated admission & contact forms, validated newsletter forms
- Current year in the footer generated by JavaScript
- Full `prefers-reduced-motion` support and visible focus states

## 3. How the Shared Header & Footer Work

To keep the theme DRY, the announcement bar, header, mobile panel and footer are injected by
`js/navigation.js`. Every page contains:

```html
<body data-page="about">                 <!-- controls the active nav link -->
  <div data-component="header"></div>
  <main id="main"> … page content … </main>
  <div data-component="footer"></div>
  <script src="js/navigation.js" defer></script>
  <script src="js/main.js" defer></script>
</body>
```

All site details (phone, email, address, programs, social links) live in the `SITE` object at the
top of `js/navigation.js` — edit it once to update the whole site.

## 4. Running the Website Locally

No installation or build step is required.

**Option A — open directly**
1. Open the `preschool-stackly` folder.
2. Double-click `index.html` to open it in your browser.

**Option B — local server (recommended)**
Running via a local server avoids any browser file-protocol quirks.

- Using VS Code: install the **Live Server** extension, right-click `index.html` → *Open with Live Server*.
- Using Python:
  ```powershell
  cd preschool-stackly
  python -m http.server 8080
  ```
  Then visit `http://localhost:8080`.
- Using Node:
  ```powershell
  npx serve preschool-stackly
  ```

## 6. Connecting the Forms (Backend)

The admission and contact forms are **front-end demos only** — they validate input and show success
messages but do **not** send data anywhere. To make them live, pick one:

1. **Form service (easiest):** Formspree, Getform, Basin or Netlify Forms. Add your endpoint and
   remove the `e.preventDefault()` in `js/forms.js`.
2. **Your own backend:** `fetch()` the form data to your API endpoint (Node/Express, PHP, Django, etc.).
3. **Email:** use a mail service API (e.g. SendGrid) from a small serverless function.

Never handle child or family data without appropriate consent and security.

## 7. Customising the Theme

- **Colours / spacing / radius:** edit the CSS custom properties in `:root` in `css/style.css`.
- **Fonts:** swap the Google Fonts `<link>` in each page's `<head>` and update `--font-body` /
  `--font-display`.
- **Navigation & footer links:** edit `NAV_LINKS` and `SITE` in `js/navigation.js`.
- **Breakpoints:** all in one place in `css/responsive.css`.
